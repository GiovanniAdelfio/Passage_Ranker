# Passage Ranker
Developed a multi-stage Learning to Rank (LTR) pipeline combining Hybrid Retrieval (BM25 + Dense Vectors) and Cross-Encoder re-ranking on a 650k dataset. Given a query the system creates Create a 100-passages leaderboard by optimizing the MAP@10. In the datset to each query corresponds only one relevant passage. 

A comprehensive description of the work done can be found in the [Review](/Review.pdf).

It is possible to execute the code from the [notebook](https://colab.research.google.com/drive/1xu3xwYV5KfzGSo4fYHXgVd4nLT7mN2wK?usp=sharing).
